TODO-планировщик на Go

Сервис для управления задачами с возможностью поиска по ключевым словам или дате.

Описание проекта:

Веб-сервер для ведения TODO-листа с возможностью создавать, редактировать, удалять и отмечать задачи как выполненные. Поддерживаются сложные правила повторения (ежедневно, ежегодно, по дням недели, по дням месяца), поиск по тексту и дате, а также имеется аутентификация, через JWT токен.

---

Выполненные задания со звёздочкой:

- Правила повторения w — задачи по дням недели
- Правила повторения m — задачи по дням месяца
- Поиск задач — через параметр search в GET /api/tasks (по тексту и дате)
- JWT-аутентификация — через переменную окружения TODO_PASSWORD
- Docker-образ — контейнеризация приложения

Запуск проекта
Требования:
	Go 1.26 или выше, т.к. Go Mod для версии 1.26.4
	SQLite3 (устанавливается автоматически через зависимости)

Локальный запуск

1. Склонируйте репозиторий:
	git clone git@github.com:UGRORF/go-todo.git
	cd go-todo
2. Установка зависимостей
	go mod download

3. Переменные окружения. 
	Создайте файл .env по аналогии с .env.example
	# Обязательные переменные
	TODO_PORT=7540 (Порт для запуска приложения)
	TODO_DBFILE=./scheduler.db (путь к файлу DB)

	# Опциональные переменные (для аутентификации)
	TODO_PASSWORD=12345 (Ваш пароль)
	TODO_JWT_SECRET=xxxxxx (Ваш пароль для подписи JWT-токена)

4. Запуск сервера:
	go run cmd/server/main.go
	
5. Открытие в браузере:
	http://localhost:7540
	где 7540 - ваш порт из переменной TODO_PORT

1. Перед запуском тестов откройте файл tests/settings.go и проверьте настройки:
var Port = 7540                  // Порт сервера (должен совпадать с TODO_PORT)
var DBFile = "../scheduler.db"    // Путь к файлу БД (относительно папки tests)
var FullNextDate = true           // true = реализованы правила w и m
var Search = true                 // true = реализован поиск по задачам
var Token = ``                    // JWT токен (оставьте пустым, если пароль не задан)

2. Запустить сервер с паролем
3. Получить токен через /api/signin
4. Вставить токен в поле Token
5. go test ./tests

Инструкция по сборке и запуску через Docker
Требования: Установленный docker

1. Сборка Docker - образа
	docker build -t todo-server .

2. Запуск Docker - контейнера
		docker run -d \
  		--name todo-app \
  		-p 7540:7540 \
  		-v $(pwd)/data:/app/data \
  		-e TODO_PASSWORD=12345 \
  		-e TODO_JWT_SECRET=xxxxxx \
  		todo-server


	если нужен кастомный порт, то 
		docker run -d \
  		--name todo-app \
  		-p number_port:7540 \
  		-v $(pwd)/data:/app/data \
  		-e TODO_PASSWORD=12345 \
  		-e TODO_JWT_SECRET=xxxxxx \
  		todo-server

		number_port - номер нужного порта

3. Проверка, что контейнер запущен
	docker ps

4. Далее аналогично локальному запуску:
	
	Открытие в браузере:
	http://localhost:7540
	где номер порта = number_port
